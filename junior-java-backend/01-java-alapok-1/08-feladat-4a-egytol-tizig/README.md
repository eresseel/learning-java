# Feladat IV.A – Számok egytől tízig

> Tananyag: Junior Java Backend fejlesztő I. – Java alapok I. (JuniorJavaBackend_01.pdf), Feladat IV.A – lásd a [lecke áttekintőjét](../README.md).

## Feladat

- Írjuk ki egytől tízig a számokat.

## Mit mutat be?

- Számlálós ciklus (`for`): inicializálás, feltétel, növekmény.
- Ha előre tudjuk az ismétlések számát, a `for` a legtermészetesebb választás.

## Fájlok

- `src/App.java` – a program.

## Futtatás

A feladat mappájából:

```bash
javac -d out src/*.java
```

```bash
java -cp out App
```
