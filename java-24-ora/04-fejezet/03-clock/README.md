# Clock

> Tananyag: Java 24 óra alatt – lásd a [tananyag áttekintőjét](../../README.md).

## Mit mutat be?

Saját `JPanel` komponens: az aktuális dátum és idő megjelenítése.

## Fájlok

- `src/App.java`
- `src/ClockPanel.java`

## Futtatás

A feladat mappájából:

```bash
javac -d out src/*.java
```

```bash
java -cp out App
```
