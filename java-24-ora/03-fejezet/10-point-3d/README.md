# Point3D

> Tananyag: Java 24 óra alatt – lásd a [tananyag áttekintőjét](../../README.md).

## Mit mutat be?

A `java.awt.Point` kiterjesztése háromdimenziós ponttá, metódusok felülírása.

## Fájlok

- `src/App.java`
- `src/Point3D.java`

## Futtatás

A feladat mappájából:

```bash
javac -d out src/*.java
```

```bash
java -cp out App
```
