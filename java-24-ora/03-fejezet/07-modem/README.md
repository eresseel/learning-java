# Modem

> Tananyag: Java 24 óra alatt – lásd a [tananyag áttekintőjét](../../README.md).

## Mit mutat be?

Öröklődés: közös `Modem` ősosztály és `CableModem`, `DslModem`, `AcousticModem` leszármazottak.

## Fájlok

- `src/AcousticModem.java`
- `src/App.java`
- `src/CableModem.java`
- `src/DslModem.java`
- `src/Modem.java`

## Futtatás

A feladat mappájából:

```bash
javac -d out src/*.java
```

```bash
java -cp out App
```
