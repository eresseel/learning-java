# Tanulok

> Tananyag: Java 24 óra alatt – lásd a [tananyag áttekintőjét](../../README.md).

## Mit mutat be?

Kétdimenziós (szabálytalan) tömb bejárása, tanulói átlagok számítása.

## Fájlok

- `src/App.java`

## Futtatás

A feladat mappájából:

```bash
javac -d out src/*.java
```

```bash
java -cp out App
```
