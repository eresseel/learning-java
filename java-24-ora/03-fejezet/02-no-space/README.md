# NoSpace

> Tananyag: Java 24 óra alatt – lásd a [tananyag áttekintőjét](../../README.md).

## Mit mutat be?

Sztring karaktertömbbé alakítása (`toCharArray()`), szóközök cseréje feltételes operátorral.

## Fájlok

- `src/App.java`

## Futtatás

A feladat mappájából:

```bash
javac -d out src/*.java
```

```bash
java -cp out App
```
