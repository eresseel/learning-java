# biciklik

> Tananyag: Java programozás 1.3 – lásd a [tananyag áttekintőjét](../README.md).

## Mit mutat be?

Osztály és objektumok: a `Bicycle` osztály példányainak állapotváltozása.

## Fájlok

- `src/App.java`
- `src/Bicycle.java`

## Futtatás

A feladat mappájából:

```bash
javac -d out src/*.java
```

```bash
java -cp out App
```
